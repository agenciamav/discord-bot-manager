# Arquivos de Áudio para o Bot

O bot espera encontrar os seguintes arquivos de áudio na pasta `/audio/`:

- `welcome.mp3` - Som de boas-vindas
- `alert.mp3` - Som de alerta
- `goodbye.mp3` - Som de despedida

Você precisa adicionar estes arquivos para que o comando `/play` funcione corretamente.

## Recomendações

1. Os arquivos devem estar no formato MP3
2. Mantenha-os curtos (1-5 segundos) para melhor experiência
3. Use arquivos de boa qualidade (128kbps+)
4. Evite volume muito alto ou baixo
